# VibraCoach Website

The website for **VibraCoach**, a prototype developed at the Open Hackathon for Accessibility 2026.

VibraCoach explores how haptic feedback can help deaf and hard-of-hearing athletes receive coaching cues without relying on visual or auditory signals. The project combines an Android app with a wearable device built around the ESP32-C3, communicating over Bluetooth Low Energy (BLE).

This repository contains the website used to present the project, explain the development process, and showcase the hardware concept.

**Live website:** [aggelosladas.com/VibraCoach](https://www.aggelosladas.com/VibraCoach/)

## What's on the website

- **Project overview** — the problem VibraCoach aims to address and the approach behind it.
- **Development process** — photos and notes from the three-day hackathon.
- **Hardware showcase** — interactive 3D models of the proposed wearable, including an internal view.
- **Project presentation** — the pitch and background behind the prototype.

## Tech Stack

- CSS

## Project Background

VibraCoach was developed by Team Kronos during the Open Hackathon for Accessibility 2026. The prototype explores a simple idea: delivering coaching instructions through vibration rather than sound or visual cues.

The website documents both the idea and the work involved in turning it into a working prototype.
